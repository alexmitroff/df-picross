# Credits

## Harbour Picross — Defold Port

A cross-platform port of **Harbour Picross (Picross 2)**, rebuilt using the [Defold](https://defold.com/) game engine.

This project aims to preserve the original game's puzzles and gameplay while providing a native Defold implementation.

## Original Game

**Harbour Picross**
- Original developer: [Baspar](https://github.com/Baspar)
- Original source: https://github.com/Baspar/harbour-picross
- Original gameplay implementation and the majority of puzzle levels.

**Picross 2**
- Developer and maintainer: [direc85](https://github.com/direc85)
- Source: https://github.com/direc85/harbour-picross
- Maintenance, bug fixes, visual improvements, and additional content.

Special thanks to both developers for creating, maintaining, and sharing the original game as free and open-source software.

## Defold Port

- Development and implementation: Aleksei Mitrofanov
- Game engine: [Defold](https://defold.com/)
- Programming language: Lua

The Defold port is a separate implementation and is not an official release of the original Harbour Picross project.
